# DockStacks 11.0.0 — Actualizaciones opcionales

- Buscar actualizaciones al abrir el gestor o mediante el botón manual.
- Solo Releases estables del repositorio oficial; ignora borradores y pruebas.
- Aviso y botones Ver cambios, Actualizar ahora y Más tarde.
- Revisión diaria opcional mediante systemd de usuario: desactivada por defecto.
- El interruptor habilita o detiene el temporizador; no hay instalaciones automáticas.
- Notificación de escritorio aunque el gestor esté cerrado, si se habilita la revisión diaria.
- Paquete completo con comprobación SHA-256 informada por GitHub.
- Respaldo de gestor y extensión; recuperación de archivos si falla la instalación.
- Conserva iconos, ajustes y el estado de activación previo. Tras actualizar requiere cerrar sesión.
- Publicación automatizada de Releases con etiqueta y descarga fija mediante GitHub Actions.

La extensión conserva las funciones visuales de la versión 10. Esta versión añade el sistema de actualización. Las pruebas automatizadas cubren sus rutas principales; la prueba real del aviso se realizará con la siguiente publicación.
